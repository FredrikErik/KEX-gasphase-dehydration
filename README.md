# KEX-gasphase-dehydration
Detta repository innehåller kod för ett distribuerat styrsystem med två ESP32, en för styrning och en för UI, som utvecklats inom ett kandidatarbete i mekatronik vid KTH. Projektet avser konstruktion och utvärdering av en småskalig bänkapparat för gasfasdehydrering, med fokus på temperaturreglering i ett uppvärmt reaktorrör.
